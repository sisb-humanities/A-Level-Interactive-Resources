# AS & A Level Economics (9708) — Interactive Hub

Upload every file in this folder to the root of a new GitHub repository
(GitHub web UI: "Add file" → "Upload files", drag all 8 files in, commit),
then turn on GitHub Pages (Settings → Pages → Deploy from branch → main / root).

Files:
- index.html                              — the hub / landing page
- sisb-alevel-exam-skills.html             — exam skills toolkit
- sisb-alevel-econ-1_1-interactive.html    — Topic 1.1
- sisb-alevel-econ-1_2-interactive.html    — Topic 1.2
- sisb-alevel-econ-1_3-interactive.html    — Topic 1.3
- sisb-alevel-styles.css                   — shared stylesheet
- sisb-tracker.js                          — student name + progress tracker
- sisb-dragdrop.js                         — drag & drop engine

To add a new topic later: name the file
    sisb-alevel-econ-X_Y-interactive.html
and it will appear on the hub automatically (once REPO_OWNER / REPO_NAME
are set near the bottom of index.html's <script>).
